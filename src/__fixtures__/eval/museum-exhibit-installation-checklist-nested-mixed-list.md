# Exhibit Installation Checklist

Use this sequence for the maritime gallery refresh scheduled before the public preview on Friday.

1. Prepare the entry bay
   1. Confirm wall labels are printed and trimmed
      1. Check the title panel for the _North Atlantic Crossing_ section
         1. Replace any label with visible toner streaks
   2. Verify adhesive strips are rated for painted masonry
2. Stage display cases
   1. Position the brass compass case under track light B
      1. Use foam shims if the base rocks
         1. Record shim thickness in the install log
            1. If thickness exceeds 6 mm, notify conservation
      2. Secure the vitrine lock and test both keys
3. Mount graphics
   1. Hang the harbor panorama at eye level
      1. Center on the blue datum line marked by facilities
         1. Do not cover the emergency shutoff placard
   2. Install donor credits beside the exit arch
4. Final walkthrough
   1. Test audio loop volume from three visitor positions
      1. Note any narration clipping during the storm segment
         1. Request a revised file from media services if clipping persists
   2. Sign off with facilities and front-of-house

Any unresolved issue should be added to the opening-day punch list before 4:00 p.m.
